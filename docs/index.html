Stats

Leaderboards, player stats, match details, and rating history.

Get the player leaderboard

Returns competitive player statistics ordered by the selected metric. Results can be limited, filtered by a case-insensitive username query, and scoped to a rating era.

query Parameters
metric
string (LeaderboardMetric)
Default: "elo"
Enum: "elo" "winrate" "diff"

Statistic used to order the results. Defaults to elo.

q
string

Case-insensitive username search query.

limit
integer >= 1
Default: 100

Maximum number of rows to return. Defaults to 100.

era
integer >= 1
Example: era=2

Positive rating-era ID. When omitted, the latest era is used. Available eras are returned in leaderboard and player-stat responses.

Responses

Draftout production server

https://draftoutmc.com/api/stats

Get player stats and recent matches

Returns player metadata, aggregate record information, and a paginated list of matches for the selected filter. If the player is not found, the endpoint still returns HTTP 200 with player: null and empty stats.

path Parameters
username
required
string
Example: Feinberg

Minecraft username.

query Parameters
page
integer >= 1
Default: 1

One-based page number. Defaults to 1.

filter
string (MatchFilter)
Default: "competitive"
Enum: "competitive" "quick-play" "lobby"

Match queue filter. Defaults to competitive.

era
integer >= 1
Example: era=2

Positive rating-era ID. When omitted, the latest era is used. Available eras are returned in leaderboard and player-stat responses.

Responses

Draftout production server

https://draftoutmc.com/api/stats/{username}

integer
